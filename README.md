# crossword_puzzle
An example tkinter project, creating a simple crossword puzzle

You can run all python files separately:

1. The "business logic", console output for main functions like word picking:

`wordbank.py`

2. "Skeleton" of gui, to test the tkinter and importing of wordbank.py:

`gui_skeleton.py`

3. "Working" gui example, needs a lot of polish to be nice, has bugs:

`crossword_app.py`
